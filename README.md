# Сайт «Центральная бухгалтерия» (Севастополь)

Статический одностраничник + `send.php` для заявок. Данные взяты с карточки Яндекс Карт (org 209932020876).

## Перед публикацией
1. **Домен.** Везде стоит заглушка `centbuh-sevastopol.ru` — заменить на настоящий во всех файлах (index.html, privacy.html, robots.txt, sitemap.xml, llms.txt).
2. **Заявки в MAX.** Скопировать `config.example.php` → `config.php` на хостинге и вписать токен бота MAX и получателя. Нужен хостинг с PHP (Beget и аналоги подходят).
   - Получатель: написать боту `/start` в личку (или добавить бота в рабочий чат и написать там), затем посмотреть id:
     `curl -H "Authorization: ТОКЕН" "https://platform-api2.max.ru/updates?limit=10"` — в ответе `sender.user_id` (личка → `max_user`) или `recipient.chat_id` (чат → `max_chat`).
   - Почта и Telegram — необязательные запасные каналы; заявка считается доставленной, если ушла хотя бы в один.
3. **Политика конфиденциальности** — шаблон; сверить с юристом/владельцем, добавить ИНН/ОГРН.
4. **Яндекс Метрика.** Вставить счётчик в `<head>` и задать `window.YM_ID = <номер>` — цели `lead_quiz` и `lead_callback` отправляются автоматически.
5. **Яндекс Вебмастер** и **Google Search Console**: подтвердить сайт, отправить sitemap, в Вебмастере указать регион «Севастополь».
6. В **Яндекс Бизнесе** (карточка на Картах) прописать адрес сайта — это главный сигнал геопривязки.

## Как править страницы
Тексты услуг, городов и статей лежат в `content.py`, шаблон — в `build.py`. После правки: `python build.py` (пересоберёт страницы, подвал главной и sitemap). Главная `index.html` правится руками, кроме блоков между маркерами `<!--FOOTER-->` и `<!--MAX-->`.
Кнопка MAX: вписать ссылку на чат в `MAX_URL` в `build.py` и пересобрать — кнопка появится на всех страницах.
Новая статья: добавить словарь в `ARTICLES` в `content.py` и пересобрать.
